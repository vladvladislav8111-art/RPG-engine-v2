# Промпт для продолжения RPG V2 разработки в новом чате

Продолжай проект «Рпг», разработку единого блока WORLD_SIMULATION_V3 для RPG-engine-v2. Не начинай игру автоматически и не меняй Шуру, день, время, деньги или CURRENT Google-файлы.

При старте: вызови RPG Runtime Bridge `runtime_health`, затем `get_turn_context`, сверь актуальный Drive `RPG V2` и `00_START_HERE`, проверяй GitHub `vladvladislav8111-art/RPG-engine-v2`. Приоритет committed runtime перед историей переписки. Никогда не делай `commit_turn` ради разработки.

Цель: единым крупным блоком, а не серией развертываний, внедрить расчёты времени, автономных расписаний NPC, ремесла и материальных ресурсов, физики боёв, маршрутов, информации и слухов, мировых событий, инвентаря и прогрессии. Подготовлено 90 DRAFT достижений, 27 DRAFT титулов с точными эффектами, 17 генеративных шаблонов квестов/заказов. У всех наград доказательства, антифарм, SUP только по канону. Права выбора маршрутов, покупок, классов и других решений остаются за Шурой. Нельзя сочинять деньги, NPC, местность, платёж, дроп или таренский словарь из броска.

В предыдущем чате создан локально протестированный pure TypeScript пакет и документация, доступные как артефакт. Найди/используй GitHub PR или ZIP, появившийся в последнем ответе, не проси игрока повторять техническое задание. Продолжай с итогов тестирования: проверь одиночный batched commit; выясни CI и Deno deploy статус; устрани ошибки локальными/CI тестами, не выкатывая каждый модуль. После согласования постоянного канона добавь только безопасный semantic adapter, fault injection и единый контролируемый production релиз. До активации достижения/титулы должны оставаться DESIGN_CANDIDATE. SUP source authority — 17_SYSTEM_INTERFACE_SUP и 03_CHARACTER_PROGRESSION... из Google Drive, прогресс только в committed runtime.

Особое требование игрока: не засорять Deno Deploy более чем 15 автоматическими развёртываниями/час. Собирать крупные изменения локально, объединять один Git tree/commit, один PR, CI, и только потом один осознанный deploy. Если чат становится слишком большим — предупреди и используй этот промпт как handoff; не обещай автоматически узнать точное число оставшихся токенов.
